# ItoCanvas Roadmap

## 1.1 — Data interchange

- Import option surfaces and contract lists from CSV
- Save named workspaces as portable documents
- Export PDF lab reports with assumptions and charts
- Add historical-volatility estimators

## 1.2 — Model depth

- Cox–Ross–Rubinstein binomial trees
- American exercise and discrete dividends
- Monte Carlo pricing with confidence intervals
- Portfolio Greeks and P&L attribution

## 2.0 — Professional workflows

- Optional user-configured market-data connectors
- Volatility-surface calibration and smile visualization
- Dynamic hedging simulator
- Reproducible notebooks and shareable analysis templates

All network features should remain opt-in. The offline core and local-data guarantees should continue to work without an account.
