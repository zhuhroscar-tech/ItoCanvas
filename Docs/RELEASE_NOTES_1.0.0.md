# ItoCanvas 1.0.0

ItoCanvas's first release is a focused, offline quantitative options laboratory for macOS.

## Included

- Black–Scholes–Merton call and put pricing
- Delta, gamma, vega, theta, and rho
- Implied-volatility solving with no-arbitrage checks
- Spot and volatility scenario analysis
- Multi-leg expiration payoff analysis and strategy presets
- Local persistence and CSV export
- Native light/dark appearance and accessible controls
- Repeatable SwiftPM build and DMG packaging

## Distribution note

The development build is ad-hoc signed for local testing. Before commercial distribution, replace the signing step with an Apple Developer ID Application identity and notarize/staple the DMG.

## Disclaimer

ItoCanvas is an educational and analytical tool. It is not investment advice, and model output is sensitive to inputs and assumptions.
