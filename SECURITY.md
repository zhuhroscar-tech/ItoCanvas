# Security Policy

## Supported version

Security fixes are applied to the latest release of ItoCanvas.

## Reporting

Please report a suspected vulnerability privately through GitHub's **Report a vulnerability** feature rather than opening a public issue. Include reproduction steps, impact, and the affected version.

## Local-data model

ItoCanvas v1 is offline-first and has no network client, account system, analytics SDK, or remote code execution path. Exported CSV files are plain text and should be handled according to the sensitivity of the user's analysis.
